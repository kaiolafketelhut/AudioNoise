### HTML!

| Tag | Was? | Beispiel |
| --- | --- | --- |
| h1! | Große Überschrift! | <h1>Hallo!</h1> |
| p! | Text! | <p>Ich bin Text!</p> |
| a! | Link! | <a href='...'>Klick!</a> |
| img! | Bild! | <img src='katze.jpg'> |

### HTML-Regel!

1. **Tag auf!** <h1>!

2. **Inhalt!** Hallo!

3. **Tag zu!** </h1>!

Immer: Auf + Inhalt + Zu! Wie Klammer!


```html
<!-- meine_seite.html - OMQ Web HTML -->
<!DOCTYPE html>
<html>
<head><title>Meine Seite!</title></head>
<body>
<h1>Hallo! Ich bin OMQ!</h1>
<p>Das ist meine erste Webseite! HTML ist einfach!</p>
<a href='https://example.com'>Klick mich!</a>
</body>
</html>
```
