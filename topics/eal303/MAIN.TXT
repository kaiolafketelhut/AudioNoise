### Liste!

| Code | Was? |
| --- | --- |
| freunde = ['Kai', 'Lena'] | Liste machen! |
| freunde[0] | Erstes Ding! Zählt bei 0! |
| freunde.append('Max') | Hinten dran! |
| len(freunde) | Wie viele? |

### Liste-Regel!

**Liste = [ ... ]! Zählt bei 0! append() = Hinten dran!**


```python
# liste.py - OMQ Python Liste!
freunde = ['Kai', 'Lena', 'Max']
print('Meine Freunde:', freunde)
print('Erster Freund:', freunde[0])
print('Wie viele?', len(freunde))
freunde.append('Sara')
print('Jetzt:', freunde)
print('Jetzt sind es', len(freunde), 'Freunde!')
for f in freunde:
    print(f'Hallo {f}! Du bist cool!')
```
