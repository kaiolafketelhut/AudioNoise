### Schleife-Regel!

**for = Feste Zahl! while = Solange! range(5) = 0,1,2,3,4!**


```python
# schleife.py - OMQ Python Schleife!
print('For-Schleife:')
for i in range(5):
    print(f'Durchgang {i}: Ich bin cool!')
print('While-Schleife:')
zahl = 0
while zahl < 3:
    print(f'Zahl ist {zahl}')
    zahl = zahl + 1
print('Fertig! Computer hat alles wiederholt!')
```
